2. Bind mount it into Nginx
==============================================================

$ docker run -d --name bind-mount-web -p 8082:80 -v /Users/vibhutibhatnagar/Desktop/SST STUDY/DEVOPS ASSIGNMENT 1/docker-networking/bind-mount/site:/usr/share/nginx/html:ro nginx:1.27-alpine
7f5344875c2a83ff9267522252efcdd8ed77024d921ec53b870dd462e54c26b8

$ docker inspect bind-mount-web --format '{{range .Mounts}}{{.Type}} {{.Source}} -> {{.Destination}} (rw={{.RW}}){{end}}'
bind /Users/vibhutibhatnagar/Desktop/SST STUDY/DEVOPS ASSIGNMENT 1/docker-networking/bind-mount/site -> /usr/share/nginx/html (rw=false)

The mount Type is 'bind', not 'volume'. Docker is not managing any storage
here; it is mapping a host directory straight into the container.

6. The mount is read-only from the container's side
==============================================================

  Refused, because the mount was made with :ro. The host stays the single
  source of truth for this content.
